
# Project Function List
## Gameplay
    + Four modes, Hard and Ett as features (Hard is an obstacle course, Ett can be freely customized, and has props, limited time).
    + You can undo your move during the game, and undo it all the time. If you can't undo it, but you still want to undo, you will trigger a small easter egg.
    + Shortcut keys (Ctrl + H to go home, Ctrl + Z to regret).
    + Lock the board when the game fails and succeeds.
    + Watch ads to revive.
## Appearance
    + Default self-made solid color background, and you can also switch between three color backgrounds.
    + Special fonts.
    + WindowsXP retro pop-up window.
    + Freely control music playback.
    + A variety of unique sound effects are waiting for you to trigger.
## Save and read files
    + Automatic save and read files.
    + Exit pop-up window to ask whether to save files.

     
## How to use
+ Download the "_2024_Spring_2048_Game". 
+ Open it in the IDEA.
+ Run the Class "Main".
